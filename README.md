# Overview

React lesson 16

This is a repo used for teaching React using Vite, NextJs with strandard UI components from ShadCN, with Tailwind for styling.

This repo is for lesson 16 in the LevelUp Coding Bootcamp delivered by Richard McSharry.

## Introduction

The repo expects an api to be running on port 8000 (a separate repo that is part of another lesson on Django and Python)

This repo is setup to use yarn, so simply type `yarn` and then `yarn dev` to run it.

Notice that the login/signup are just dummy components that do not do anything, but exist to teach about protected vs unprotected routes.
